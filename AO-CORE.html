AO-Core defines a URI-addressed protocol for describing, transporting, attesting, challenging, and tracing computations performed by many virtual machines, called devices.

This is an unofficial working draft of AO-Core 1.0. The Markdown source for the main body of this document is AO-CORE-SPEC.md; this file supplies the ReSpec wrapper, metadata, generated table of contents, references, and conformance boilerplate.
