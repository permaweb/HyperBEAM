AO-Core Spec Five-Pass Refinement

Definition: Improve AO-CORE-SPEC.md through five source-backed LFG passes that answer open questions, reduce ambiguity, and make the spec more implementable without pretending current HyperBEAM source already implements draft target behavior.

Non-goals: Do not implement Erlang behavior during this phase. Do not treat stale /docs content as authority unless confirmed by source. Do not touch unrelated untracked files such as otp/. Do not use HB_PARANOID.

Constraints

  • Work on branch wip/ao-core-spec.
  • Use current source and source tests as authority for HyperBEAM behavior.
  • Use subagents to review each pass before advancing.
  • Validation for this phase is docs/render-oriented plus source-backed review; HyperBEAM implementation tests belong to the overnight implementation phase.
  • Commit and push intended spec artifacts as wip: spec improvements.

Plan

StepAcceptance criteriaEvidence
1. Conformance and terminology Spec defines conformance classes, normative/status labels, terminology boundaries, and source/draft/profile distinctions consistently. Diff plus reviewer pass.
2. Messages, IDs, commitments, codecs Message/key, ID, commitment, private state, codec/canonicalization, and failure-mode questions are answered or explicitly labeled as source gaps. Diff plus reviewer pass.
3. Resolution, device loading, processes Base/request, resolver, device lookup/loading/trust, process/scheduler, and message extension semantics are more complete and source-backed. Diff plus reviewer pass.
4. Vary, Depends, hashpaths, witnesses Vary/Depends, result modes, hashpath profile strength, loading, witnesses, challenge, and traceability are internally consistent and implementable. Diff plus reviewer pass.
5. HTTP, examples, security, final consistency HTTP/singleton expression, examples, security/privacy considerations, registries/extension points, and final cross-references are coherent. Diff, ReSpec validation, and reviewer pass.

Validation

env -u HB_PARANOID npx --yes respec --localhost AO-CORE.html /tmp/AO-CORE.five-pass.respec.html -e -w --timeout 30

Judge Rubric

Correctness, source traceability, unanswered-question coverage, security/privacy clarity, implementation usefulness, simplicity, taste, originality, maintainability, and validation honesty.

Definition Of Done

  • Five spec passes are complete and reviewed by subagents.
  • All known unanswered questions are answered, narrowed, or explicitly labeled as source/spec gaps.
  • ReSpec render validation passes with HB_PARANOID unset.
  • The spec improvement commit is created as wip: spec improvements and pushed on wip/ao-core-spec.
